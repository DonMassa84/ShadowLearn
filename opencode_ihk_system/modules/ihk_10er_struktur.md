# IHK 10er-Struktur

Stand: 2026-05-12

## Die 10 Punkte

1. **Situation** — Ausgangslage, Kernproblem benennen
2. **SMART-Ziel** — Spezifisch, Messbar, Attraktiv, Realistisch, Terminiert
3. **Stakeholder** — Beteiligte, Betroffene, Entscheider, BR-Einbindung
4. **Ursachen** — Mensch / Organisation / Prozess (MOP)
5. **Alternativen A / B / C** — mindestens zwei realistische Optionen
6. **Bewertung** — wirtschaftlich / organisatorisch / menschlich
7. **Entscheidung + Begründung** — klare Wahl mit Abwägung
8. **Umsetzung** — wer, wann, Schritte, Ressourcen, RACI
9. **Kontrolle** — KPIs, Review-Termin, Korrekturmaßnahmen
10. **Nachhaltigkeit** — Kommunikation, Dokumentation, Recht, Transfer
